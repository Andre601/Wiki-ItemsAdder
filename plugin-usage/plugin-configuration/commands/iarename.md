# iarename

This command can be used to rename items (vanilla and custom).

It supports [font images](../../../adding-content/font-images/font-images.md) (emojis) and [text effects](../../../adding-content/text-effects-1.17+.md).

Usage example: `/iarename test <r qqqqq> :smile: very nice`

![](../../../.gitbook/assets/iarename_001.png)

### Permission

`ia.admin.iarename`
