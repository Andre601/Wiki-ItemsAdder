# Preview wiki changes

Every pull request runs an automatic GitBook check. Wait until GitHub reports **All checks have passed**, then press **Show all checks**.

<figure><img src="../.gitbook/assets/preview-wiki-changes_004.png" alt="GitHub pull request with all checks passed and the Show all checks link highlighted"><figcaption>Expand the checks section of the pull request.</figcaption></figure>

Find the **GitBook** check and press **Details**. GitBook opens a preview built from your branch, where you can inspect the edited pages before a maintainer merges the pull request.

<figure><img src="../.gitbook/assets/preview-wiki-changes_003.png" alt="Expanded GitHub checks showing the Details link for the GitBook preview"><figcaption>Open the GitBook check to view the generated preview.</figcaption></figure>

Check headings, code blocks, hints, links and images on both desktop and mobile widths. If something is wrong, commit the correction to the same branch: the pull request and its preview will update automatically.
